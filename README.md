### Интерактивная карьерная PWA-платформа и производственный симулятор для молодежи 18–26 лет
**Кейс хакатона «Открой МосПром 2026» для АО МПБК «Очаково» (https://ochakovo.ru/)**

## Инструкция по мгновенному запуску

Проект полностью настроен для немедленного запуска любым удобным способом — от одной команды в терминале до запуска в один клик.

### Способ 1. Запуск из Docker Hub в 1 команду (Рекомендуемый для жюри)

После публикации готового образа на Docker Hub запуск всего производственного комплекса выполняется одной командой:

```bash
docker run -d -p 8000:8000 --name ochakovo-app msgcg/ochakovo-career-app:latest
```

После выполнения команды сервис доступен по адресу: **http://localhost:8000/**

> [!NOTE]
> Контейнер поставляется с предкомпилированным движком распознавания речи Whisper (Vulkan GPU + CPU fallback), предзагруженными GGML-моделями, встроенным FFmpeg, системными шрифтами DejaVu, предзаполненной базой актуальных вакансий Очаково и игровыми сценариями. Никаких дополнительных действий не требуется.

### Способ 2. Локальный запуск через Docker Compose

Для запуска с автоматической сборкой образа и монтированием томов персистентности:

```bash
docker compose up -d --build
```

Проверка статуса и логов контейнера:

```bash
docker compose ps
docker compose logs -f web
```

Остановка комплекса:

```bash
docker compose down
```

### Способ 3. Локальная сборка контейнера (без публикации)

Сборка готового Linux-образа для локального тестирования:

```bash
docker build -t msgcg/ochakovo-career-app:latest .
```

Локальный запуск собранного образа:

```bash
docker run -d -p 8000:8000 --name ochakovo-app msgcg/ochakovo-career-app:latest
```

### Способ 4. Запуск на Windows в 1 клик (start.bat)

Дважды кликните по файлу **`start.bat`** в корне проекта. 
Скрипт автоматически:
1. Проверит наличие Python и создаст изолированное виртуальное окружение `.venv`.
2. Установит необходимые зависимости из `requirements.txt`.
3. Применит миграции базы данных SQLite и наполнит каталог вакансиями комбината.
4. Выполнит сборку статических файлов WhiteNoise.
5. Запустит сервер и автоматически откроет страницу в браузере по адресу `http://localhost:8000/`.

### Способ 5. Кроссплатформенный запуск через Python (run.py)

В корневой папке проекта выполните команду:

```bash
python run.py
```
*(на Linux / macOS используйте `python3 run.py`)*

Скрипт выполнит диагностику окружения, применит миграции, запустит тестовые проверки и откроет браузер.

## О кейсе хакатона и бизнес-задаче

### О предприятии «Очаково»

АО МПБК «Очаково» — ключевое и единственное крупное 100% независимое российское предприятие пищевой индустрии, основанное в 1978 году к Московской Олимпиаде-80. Комбинат производит натуральный квас двойного брожения, лимонады, комбучу, пиво, соки и питьевую воду.

### Сезонный пик и кадровая специфика

Производство имеет выраженную сезонность: с **марта по сентябрь** наступает пик потребительского спроса, когда объемы выпуска напитков достигают **1 000 000+ литров в сутки**. 

В этот период предприятию требуется оперативно привлечь сотни энергичных сотрудников и стажеров на производственные линии, участки брожения, упаковочные комплексы, лаборатории и логистический хаб.

### Условия предприятия для молодежи 18–26 лет

«Очаково» предлагает молодым специалистам, студентам и выпускникам:
- **Официальное трудоустройство по ТК РФ с первого дня практики** с полностью «белой» заработной платой.
- **Оплачиваемую производственную практику** с реальной возможностью карьерного роста до сменного мастера и инженера цеха.
- **Бесплатное корпоративное общежитие в Москве** в непосредственной близости от комбината (ул. Рябиновая, д. 44).
- **Компенсацию горячего питания** в заводских столовых.
- **Наставничество от ветеранов комбината** и ведущих инженеров пищевых биотехнологий.

### Проблема и предлагаемое решение

Традиционные доски объявлений и вакансии с текстовыми описаниями создают высокий барьер входа для зумеров и студентов. Молодежь слабо представляет реальный высокотехнологичный характер современного пищевого завода.

**Наше решение** — единая интерактивная карьерная PWA-платформа с принципом «The 5-Second Hook»:
1. Пользователь мгновенно погружается в технологический процесс через интерактивный симулятор завода («Смена на миллион литров»).
2. Решая реальные инженерные инциденты, кандидат понимает ценность технологий двойного брожения и автоматизации.
3. Достижения и заработанные баллы формируют подтвержденный «Производственный сертификат стажера», который напрямую переносится в отклик на реальные вакансии комбината на hh.ru.

## Архитектура функциональных модулей

### 1. Интерактивный симулятор завода «Смена на миллион литров»

Симулятор воспроизводит реальные условия цехов комбината «Очаково» при пиковой нагрузке:

#### Динамический HUD телеметрии
- **Температура сусла в ЦКТ (°C)**: непрерывный мониторинг охлаждения с индикацией безопасного коридора (+24.0°C...+26.5°C).
- **Плотность затора (°Bx)**: оптический контроль экстрактивности сусла и расхода сахаров.
- **Скорость конвейера розлива (банок/час)**: высокоскоростной мониторинг фасовочного триблока (до 35 000 банок в час).
- **Чистота контура CIP (%)**: контроль санитарного состояния и электропроводности моющих растворов.
- **Карусель множителя победного стрика (Win Streak Carousel)**: динамический множитель (от x1.0 до x2.0 с шагом x0.25), награждающий стажера за непрерывные серии безошибочных инженерных решений.

#### Стойка тактильного оборудования цеха (8 интерактивных приборов)
1. **Клапан охлаждения гликолевой рубашки ЦКТ**: регулировка подачи хладоносителя (-3°C) для стабилизации температуры брожения.
2. **Дозатор чистой культуры закваски 1978 года**: внесение оригинального штамма молочнокислых бактерий и дрожжей.
3. **Пульт CIP-дезинфекции**: автоматизированный контур промывки и стерилизации продуктопроводов.
4. **Кнопка аварийного останова конвейера**: моментальная остановка линии при замятии банки или угрозе повреждения оборудования Krones.
5. **Цифровой рефрактометр**: оперативное измерение оптической плотности сусла (°Brix).
6. **Органолептический бокал**: сенсорная дегустация и экспресс-оценка прозрачности, игры углекислого газа и вкуса.
7. **Интерком главного диспетчера**: селекторная связь с оперативным дежурным завода.
8. **Лабораторный pH-метр**: приборный анализ титруемой кислотности и микробиологического баланса.

#### Игровые сценарии инцидентов
- **Битва за сусло: Тонкости двойного брожения в ЦКТ №7** (Наставник: *Михалыч*, главный технолог). Предотвращение скисания 300-тонной партии кваса при перегреве затора.
- **Сбой робота-укладчика Krones на линии розлива** (Наставник: *Анна*, ведущий инженер АСУ ТП). Устранение перекоса тары при темпе 34 000 банок в час без потери сменного плана.
- **Всплеск кислотности в ЦКТ №4: Лабораторный экспресс-анализ** (Наставник: *Елена*, зав. лабораторией). Экспресс-анализ титруемой кислотности и восстановление биотехнологического баланса.
- **Складской дрифт на рампе №14** (Наставник: *Роман*, начальник терминала). Скоростное паллетирование и синхронизация отгрузок с системой WMS в пик жары.
- **Секретная варка по рецепту 1978 года** (Наставник: *Михалыч*). Воспроизведение исторической олимпийской рецептуры кваса на современном оборудовании.

### 2. Искусственный интеллект и наставничество

#### Интерактивное подключение GigaChat прямо в браузере (Предсменный инструктаж)
- Для обеспечения максимальной безопасности все постоянные ключи доступа удалены из репозитория и файла `.env`.
- При входе в любой цех симулятора перед заступлением на смену стажеру открывается интерактивное модальное окно предсменного инструктажа.
- В окне предусмотрены два сценария работы:
  1. **Онлайн-подключение Сбер GigaChat API**: стажер указывает свои персональные `Client ID` и `Client Secret` (или готовый `Base64 Auth Key`), бесплатно получаемые в [Studio Salute (developers.sber.ru)](https://developers.sber.ru/) с квотой 1 000 000 токенов в месяц. Система валидирует ключи через официальный шлюз `ngw.devices.sberbank.ru:9443` в реальном времени и сохраняет их в изолированной сессии браузера (`request.session`) без записи на диск сервера.
  2. **Встроенный офлайн-движок (Smart Biochemical Engine)**: нажатием кнопки «Играть офлайн» стажер запускает симулятор в полностью автономном режиме закрытого производственного контура.
- **Интерактивный статус-бейдж в HUD**: в верхней панели приборов отображается текущий статус («GigaChat AI» с зеленым индикатором или «Офлайн AI» с синим индикатором). Клик по бейджу в любой момент смены открывает окно настроек для быстрой смены режима или обновления ключей.

#### Сбер GigaChat Max с Function Calling
В симулятор интегрирована большая языковая модель GigaChat с декларативным вызовом функций:
- `complete_shift`: фиксация успешного или аварийного исхода смены с детальным технологическим разбором и расчетом баллов.
- `resolve_production_incident`: оценка промежуточных действий кандидата, корректировка параметров цеха и динамическая реакция наставника.
- `offer_hints`: выдача контекстных тактических подсказок и вариантов действий при затруднении стажера.

#### Персонализированные наставники и динамические интерфейсы
- С кандидатом взаимодействуют наставники с уникальными характерами и профессиональным сленгом: Михалыч (производство кваса), Анна (робототехника и АСУ ТП), Елена (контроль качества и микробиология), Роман (складская логистика).
- Кнопки взаимодействия адаптируются под активного наставника: например, «Спросить совета у Елены» или «Спросить совета у Михалыча».

#### Контроль прокрастинации и аварийная логика
- Если стажер в критической ситуации неоднократно предлагает бездействовать, ждать или откладывать решения (когда температура сусла растет или конвейер заклинен), наставник делает до двух строгих замечаний.
- При третьей попытке бездействия смена немедленно завершается со статусом «Смена сорвана», фиксируется производственный инцидент со штрафом к квалификационному рейтингу.

#### Smart Biochemical Offline Engine
- При отсутствии API-ключей GigaChat или отсутствии подключения к внешней сети автоматически активируется автономный биохимический движок.
- Движок рассчитывает параметры брожения по математической модели кинетики ферментации (температурные зависимости, баланс молочной кислоты и дрожжей, расход сахаров) и гарантирует 100% работоспособность сценариев на любых стендах и проверках.

### 3. Голосовой ввод и распознавание речи (ASR)

#### Локальный движок whisper.cpp с ускорением Vulkan GPU
- Высокоскоростное распознавание голосовых команд стажера через локальный C++ бинарник whisper.cpp.
- Поддержка аппаратного ускорения Vulkan GPU на видеокартах NVIDIA (RTX/GTX), AMD Radeon и Intel Arc.
- Прозрачный автоматический fallback на оптимизированный CPU-режим при недоступности Vulkan.
- Управление режимом через переменные окружения: `GGML_ACCELERATION=auto|vulkan|cpu` и `GGML_VULKAN_FALLBACK_CPU=True`.
- Специализированный контекстный промпт для Whisper, повышающий точность распознавания заводских терминов («ЦКТ», «гликоль», «Krones», «CIP-мойка», «рефрактометр», «дрожжи», «лактобактерии»).

#### Клиентский Web Speech API
- Для мобильных устройств и браузеров реализован прозрачный резервный голосовой ввод через Web Speech API без отправки тяжелых аудиофайлов.

### 5. Центр прогресса стажера и сертификация

#### Система квалификационных разрядов
По мере решения инцидентов стажер накапливает квалификационные баллы (XP):
- **Кандидат-практикант**: 0 – 89 баллов;
- **Младший сменный мастер**: 90 – 179 баллов;
- **Инженер-технолог смены**: 180 – 269 баллов;
- **Шеф-наставник комбината**: 270+ баллов.

#### Зал трудовой славы
Система включает 6 разблокируемых квалификационных достижений:
1. «Олимпиец 1978» — сохранение традиций комбината;
2. «Хранитель закваски» — идеальный баланс дрожжей и молочнокислых бактерий;
3. «Повелитель Krones» — безаварийная работа упаковочного робота на максимальной скорости;
4. «Лабораторный ас» — безошибочный контроль плотности и кислотности сусла;
5. «Мастер двойного брожения» — спасение 300-тонного танка брожения;
6. «Шеф смены на миллион» — высший балл во всех производственных цехах.

#### Официальный Производственный сертификат стажера
- Генерируется на странице `/progress/` на основе фактических результатов смен.
- Содержит верифицированный список решенных кейсов, набранные баллы, технологические навыки и разбор наставников.

#### Прямой мост с HeadHunter (hh.ru)
- Автоматическая передача данных кандидата и текста сертификата в реальную форму отклика на проверенные вакансии «Очаково» на hh.ru.
- Валидация прямых URL вакансий и защита от ошибок 404 через резервные канонические ссылки комбината.

## Конфигурация окружения (.env)

Основные переменные конфигурации:

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `SECRET_KEY` | django-insecure-ochakovo-production-secret-key-moscow-2026 | Секретный ключ Django |
| `DEBUG` | True | Режим отладки (False для продакшена) |
| `ALLOWED_HOSTS` | * | Разрешенные хосты |
| `GIGACHAT_CLIENT_ID` | *(пусто)* | Client ID Сбер GigaChat API (также вводится в веб-интерфейсе) |
| `GIGACHAT_CLIENT_SECRET` | *(пусто)* | Client Secret Сбер GigaChat API (также вводится в веб-интерфейсе) |
| `GIGACHAT_AUTH_KEY` | *(пусто)* | Опциональный Base64-ключ авторизации Сбер GigaChat |
| `GIGACHAT_SCOPE` | GIGACHAT_API_PERS | Область доступа GigaChat (`GIGACHAT_API_PERS` или `GIGACHAT_API_CORP`) |
| `GIGACHAT_MODEL` | GigaChat-Max | Версия модели языкового наставника |
| `GGML_ACCELERATION` | auto | Режим ускорения Whisper (`auto`, `vulkan`, `cpu`) |
| `GGML_VULKAN_FALLBACK_CPU` | True | Автоматический переход на CPU при ошибках Vulkan |
| `WHISPER_BIN_PATH` | *(автопоиск)* | Явный путь к исполняемому файлу whisper-cli |
| `WHISPER_MODEL_PATH` | *(автопоиск)* | Явный путь к GGML-модели распознавания речи |

> [!NOTE]
> Все секретные ключи доступа по умолчанию исключены из файла `.env`. Настройка подключения к GigaChat выполняется интерактивно прямо в браузере перед заступлением на смену, либо через переменные окружения при серверном развертывании. Приложение 100% работоспособно без ключей благодаря встроенному Smart Biochemical Engine.

## Проверка работоспособности и тестирование

### Системная диагностика Django
Для проверки корректности конфигурации, целостности моделей и ссылок выполните:

```bash
python manage.py check
```

### Комплексный прогон автоматических тестов
В проект встроена команда автоматического тестирования всех ключевых компонентов:

```bash
python manage.py smoke_tests
```

Тестирование включает:
1. Проверку доступности и корректности главной страницы, каталога и симулятора.
2. Проверку генерации PWA-манифеста и отдачи Service Worker.
3. Проверку инициализации игровых сессий и вычисления технологических дельт.
4. Проверку сценариев работы ИИ-наставника (Function Calling и Smart Offline).
5. Проверку распознавания речи через сервис Whisper (Vulkan/CPU).
6. Проверку работы краулера и regex-матчера вакансий.
