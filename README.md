# Проект «Очаково: Мастерская Натурального Вкуса»

### Интерактивная карьерная PWA-платформа и производственный симулятор для молодежи 18–26 лет

**Кейс хакатона «Открой МосПром 2026» для АО МПБК «Очаково» (https://ochakovo.ru/)**

---

## Быстрый запуск из Docker Hub

Готовый собранный образ доступен в официальном публичном реестре Docker Hub. Запуск всего производственного комплекса выполняется одной командой:

```bash
docker run -d -p 8080:8080 --name ochakovo-app makushimu11/ochakovo-career-app:latest
```

После выполнения команды сервис доступен в браузере:

- Основной портал и симулятор: **http://localhost:8080/**
- Панель управления HR и наставников: **http://localhost:8080/admin/**
- Сквозной аналитический дашборд: **http://localhost:8080/admin/analytics/**

Учетные данные администратора по умолчанию:

- Логин: **admin**
- Пароль: **ochakovo2026**

Контейнер полностью автономен: содержит предкомпилированный движок Whisper (Vulkan GPU + CPU fallback), предзагруженные GGML-модели распознавания речи, встроенный FFmpeg, системные шрифты, предзаполненную базу вакансий комбината и все 7 производственных сценариев.

## Панель управления HR и наставников завода

В платформе развернута полнофункциональная панель администратора на русском языке для HR-специалистов, позволяющая в реальном времени контролировать воронку соискателей:

- Адрес панели: `http://localhost:8080/admin/`
- Сквозная аналитика: `http://localhost:8080/admin/analytics/`
- Логин: `admin`
- Пароль: `ochakovo2026`

### Возможности HR-панели и модуля аналитики:

1. Единый журнал кандидатов: ФИО, учебное заведение (ВУЗ/колледж), прямые ссылки на профили ВКонтакте, телефоны, Telegram.
2. Суммарный карьерный скор (XP): наглядная индикация квалификационного разряда (Высший разряд >200 XP, 2-й разряд >100 XP, Стажер).
3. Рекомендованная должность: автоматический подбор позиции на основе результатов прохождения смен (например, Мастер-технолог бродильного цеха, Инженер линий Krones) и расчет бонуса стажировки (сокращение срока испытания до 50%).
4. Аналитический модуль учета посетителей: учет каждого захода на сайт (источник трафика, тип устройства, переход по QR со стенда, реферер ВКонтакте, отслеживание воронки конверсии из гостя в лида).
5. Экспорт данных: мгновенная выгрузка базы кандидатов и журнала посещений в CSV-формат (Excel с корректной кодировкой UTF-8 BOM).
6. Настройка языковой модели: возможность централизованной конфигурации корпоративных ключей Сбер GigaChat API прямо через веб-интерфейс без перезапуска контейнера.

## Способы локального запуска и разработки

### Способ 1. Запуск через Docker Compose

Для запуска с автоматической сборкой и монтированием томов персистентности базы данных и статики:

```bash
docker compose up -d --build
```

Проверка статуса и логов контейнера:

```bash
docker compose ps
docker compose logs -f web
```

Остановка комплекса:

```bash
docker compose down
```

### Способ 2. Сборка и публикация образа в Docker Hub (аккаунт makushimu11)

Инструкция для повторной сборки и загрузки обновленного образа в реестр Docker Hub:

1. Авторизация в Docker Hub:

```bash
docker login -u makushimu11
```

2. Сборка Docker-образа:

```bash
docker build -t makushimu11/ochakovo-career-app:latest .
```

3. Присвоение версионного тега (рекомендуется):

```bash
docker tag makushimu11/ochakovo-career-app:latest makushimu11/ochakovo-career-app:v1.1
```

4. Публикация в Docker Hub:

```bash
docker push makushimu11/ochakovo-career-app:latest
docker push makushimu11/ochakovo-career-app:v1.1
```

5. Проверка запуска опубликованного образа:

```bash
docker run -d -p 8080:8080 --name ochakovo-app makushimu11/ochakovo-career-app:latest
```

### Способ 3. Запуск на Windows в один клик (start.bat)

Дважды кликните по файлу `start.bat` в корне проекта. Скрипт в автоматическом режиме:

1. Создаст изолированное виртуальное окружение `.venv` (если отсутствует).
2. Установит необходимые зависимости из `requirements.txt`.
3. Применит миграции базы данных SQLite и наполнит каталог вакансиями и сценариями.
4. Выполнит сборку статических файлов WhiteNoise (`collectstatic`).
5. Запустит веб-сервер и откроет страницу в браузере по адресу `http://localhost:8080/`.

### Способ 4. Кроссплатформенный запуск через Python (run.py)

В корневой папке проекта выполните команду:

```bash
python run.py
```

*(на Linux / macOS используйте `python3 run.py`)*

## О кейсе хакатона и бизнес-задаче

### О предприятии «Очаково»

АО МПБК «Очаково» — ключевое и единственное крупное 100% независимое российское предприятие пищевой индустрии, основанное в 1978 году к Московской Олимпиаде-80. Комбинат производит натуральный квас двойного брожения, лимонады, соки, комбучу и напитки без использования синтетических консервантов.

### Сезонный пик и кадровая специфика

С марта по сентябрь наступает пик потребительского спроса, когда объемы выпуска напитков достигают 1 000 000+ литров в сутки. В этот период предприятию требуется оперативно привлечь сотни молодых специалистов и стажеров на производственные линии, участки брожения, упаковочные комплексы, в лаборатории и складской комплекс.

### Условия предприятия для молодежи 18–26 лет:

- Официальное трудоустройство по ТК РФ с первого дня с полностью белой заработной платой.
- Оплачиваемая практика с реальной перспективой перехода на должность сменного мастера или инженера.
- Бесплатное корпоративное общежитие в Москве рядом с комбинатом (ул. Рябиновая, д. 44).
- Компенсация горячего питания в заводской столовой.
- Наставничество от ведущих инженеров пищевой отрасли.

## Архитектура и функциональные модули платформы

### 1. Интерактивный симулятор завода (7 производственных кейсов)

Симулятор моделирует реальные технологические процессы и нештатные ситуации в цехах комбината:

1. **Дрожжевой флекс в ЦКТ №7** (`brew-yeast-flex`):

   - Цех: Бродильное отделение.
   - Наставник: Михалыч (главный технолог-квасовар).
   - Задача: ликвидация перегрева затора в ЦКТ емкостью 500 тонн при активном брожении, регулировка подачи хладоносителя и сохранение штамма дрожжей.
2. **Двойное брожение: Секрет белого кваса** (`brew-double-fermentation`):

   - Цех: Отделение комбинированного брожения.
   - Наставник: Михалыч.
   - Задача: точный баланс между чистой культурой дрожжей и молочнокислыми бактериями для получения традиционного освежающего белого кваса.
3. **Роботы Krones в тильте** (`krones-robot-tilt`):

   - Цех: Линия розлива Krones.
   - Наставник: Анна (ведущий инженер розлива).
   - Задача: юстировка упаковочного робота при скорости до 50 000 банок в час, предотвращение замятия тары.
4. **Сбой на линии розлива: Затор на этикетировочном автомате** (`bot-line-glitch`):

   - Цех: Скоростной фасовочный конвейер.
   - Наставник: Анна.
   - Задача: калибровка фотодатчиков и аппликатора этикеток без остановки сменного плана.
5. **Окрошечный детектив: Квас против Кефира** (`okroshka-detective`):

   - Цех: Исследовательская лаборатория микробиологии и ОТК.
   - Наставник: Елена (руководитель лаборатории).
   - Задача: приборный контроль титруемой кислотности, плотности сусла по шкале Brix и микробиологической чистоты.
6. **Форсаж на электрокаре: Пик отгрузки** (`warehouse-drift`):

   - Цех: Логистический терминал WMS.
   - Наставник: Роман (начальник складского комплекса).
   - Задача: координация штабелеров, скоростное паллетирование и синхронизация отгрузок автопоездов в летний зной.
7. **Секретный дроп 1978: Рецепт Олимпиады** (`secret-drop-1978`):

   - Цех: Креативный хаб и R&D центр.
   - Наставник: Артем (бренд-стратег и купажист).
   - Задача: воспроизведение исторической олимпийской рецептуры кваса с использованием солодовых экстрактов на современном оборудовании.

#### Оснащение HUD симулятора:

- Динамические датчики: температура сусла (°C), плотность сахаров (°Bx), темп фасовки (банок/час), чистота контура CIP (%), баланс кислотности (pH).
- Интерактивная стойка из 8 инструментов: клапан рубашки охлаждения, дозатор чистой культуры закваски 1978 года, пульт дезинфекции CIP, аварийный останов конвейера, цифровой рефрактометр, дегустационный бокал, интерком связи с диспетчером, лабораторный pH-метр.
- Множитель безошибочной серии (Win Streak Combo): повышение финального балла за серию верных инженерных решений без замечаний наставника.

### 2. Поддержка искусственного интеллекта и офлайн-движок

- **Сбер GigaChat с Function Calling**: вызов системных функций `complete_shift`, `resolve_production_incident`, `offer_hints` с разбором каждого действия кандидата.
- **Интерактивная настройка ключей**: стажер может указать персональные ключи доступа Salute Developers прямо в окне предсменного инструктажа, сохранив их в сессии без передачи на постоянное хранение на сервере.
- **Smart Biochemical Offline Engine**: при отсутствии подключения к сети или API-ключей автоматически вступает в работу математическая модель кинетики брожения, гарантирующая 100% стабильность демонстрации на любых выставочных стендах.

---

### 3. Голосовой ввод и распознавание речи (ASR)

- **Linux Docker**: локальный высокопроизводительный движок `whisper.cpp` с поддержкой аппаратного ускорения Vulkan GPU (NVIDIA/AMD/Intel) и прозрачным автоматическим переключением на CPU (AVX2).
- **Windows-отладка**: автоматический переход на Web Speech API при отсутствии скомпилированных бинарных файлов Whisper.
- **Управление в стиле современных мессенджеров**: старт записи по первому тапу на иконку микрофона, завершение и мгновенная отправка реплики — по повторному тапу.
- **Живой аудиовизуализатор**: отображение частотного спектра звука для наглядного контроля уровня входящего сигнала микрофона.
- **Возможность редактирования**: распознанный текст помещается в поле ввода и доступен для ручной корректировки перед отправкой.

---

### 4. Автономность PWA и надежный Service Worker (v1.1.0)

- **Полное предкэширование**: в кэш устройства заранее загружаются все 7 сценариев, каталог вакансий, история предприятия, личный кабинет и графические ассеты цехов.
- **Интеллектуальная офлайн-страница (`/offline/`)**: при потере интернет-соединения пользователь видит полноценный дашборд с доступом ко всем 7 цехам комбината, а не тупиковую заглушку.
- **Локальный расчет ходов в браузере**: функция `handleClientOfflineTurn` в `simulator.js` обрабатывает действия стажера локально, обновляет датчики и фиксирует прогресс в `localStorage`.
- **Изоляция видеопотоков**: запросы к видеороликам цехов исключены из перехвата Service Worker, что исключает ошибки Range-запросов (HTTP 206) при воспроизведении.

---

### 5. Модуль сквозной аналитики и учет посетителей

- Модель `SiteVisitor` фиксирует каждый уникальный визит: IP-адрес, User-Agent, платформу (мобильная/десктоп), источник перехода (QR-стенд на форуме, ВКонтакте, прямой заход).
- Аналитический экран `/admin/analytics/` выводит общую статистику просмотров, воронку конверсии от первого визита до завершения смены и отклика на вакансию, а также распределение кандидатов по ВУЗам и городам.

---

### 6. Экспресс-вход для карьерных выставок и форумов

- **Динамический QR-код стенда** (`/api/stand/qr/`): генерирует векторный сканируемый SVG-код с автоматическим определением текущего домена и протокола (localhost, рабочий IP или облачный домен).
- **Сбор лидов на планшетах стенда** (`/api/candidate/stand-lead/`): экспресс-форма для быстрой фиксации контактов студента без прохождения полного анкетирования.
- **Авторизация через VK ID**: поддержка мгновенного входа по ссылке на профиль ВКонтакте без пароля.

---

### 7. Связка с HeadHunter и сертификация

- Формирование официального «Производственного сертификата стажера» по результатам прохождения смен.
- Прямой переход к отклику на актуальные вакансии «Очаково» на hh.ru с автоматическим заполнением сопроводительного письма и результатов практики.

## Проверка работоспособности и тестирование

### Системная диагностика Django

Для проверки корректности конфигурации, целостности моделей и ссылок выполните:

```bash
python manage.py check
```

### Комплексный прогон автоматических тестов

В проект встроена команда автоматического тестирования всех ключевых компонентов:

```bash
python manage.py smoke_tests
```

Прогон включает 13 автоматических проверок:

1. Подключение и целостность базы данных SQLite.
2. Наличие сценариев и связей в базе данных.
3. Доступность главной страницы (200 OK).
4. Доступность каталога вакансий (200 OK).
5. Доступность каталога симулятора (200 OK).
6. Доступность экрана прогресса стажера (200 OK).
7. Доступность исторического раздела (200 OK).
8. Корректность генерации PWA-манифеста (`manifest.json`).
9. Корректность отдачи Service Worker (`sw.js`) и заголовок `Service-Worker-Allowed`.
10. Работоспособность AJAX API поиска вакансий (`/api/vacancies/search/`).
11. Корректность работы Regex-сопоставителя вакансий и сценариев.
12. Диагностика сервиса распознавания речи Whisper (Vulkan/CPU fallback).
13. Проверка создания учетной записи администратора и целостности моделей.

## Безопасность и соответствие стандартам

- Исходный код не содержит конфиденциальных данных и персональных секретных ключей в открытом виде.
- Файлы базы данных SQLite (`*.sqlite3`), каталоги виртуального окружения (`.venv`), временные медиа-файлы и локальные переменные внесены в `.gitignore` и исключены из репозитория.
- Шаблоны полностью соответствуют стандартам доступности W3C и семантической разметке HTML5.
- Все внешние ссылки на вакансии HeadHunter валидируются для предотвращения переходов на несуществующие страницы.
- Полное отсутствие эмодзи в интерфейсе и документации в соответствии со строгим корпоративным стилем инженерного портала.
